# FDE Study

Flashcards for the Forward-Deployed Engineer question bank.

- `index.html`: a flashcard page that reads `forward-deployed-engineer/questions.md`. You can study all cards or one section, shuffle them, mark each card as known or not known, and reset your progress. Progress is saved in your browser's localStorage.
- `Software-Engineering/`: coding-pattern cheatsheet images (Arrays, Two Pointers, Stack) and `questions.md`, a text version of them that the page loads as the **Software Engineering** deck. Use the deck dropdown to switch between decks.
- `forward-deployed-engineer/`: a copy of the FDE section of [aishwaryanr/awesome-generative-ai-guide](https://github.com/aishwaryanr/awesome-generative-ai-guide/tree/main/interview_prep/roles/forward-deployed-engineer) (MIT License).

To host it: go to **Settings → Pages**, choose **Deploy from a branch**, then pick `main` and `/ (root)`.

To run it locally: `python3 -m http.server`, then open http://localhost:8000.
